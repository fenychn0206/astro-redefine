# Theme Documentation

This directory contains the documentation for the Astro Redefine theme.

- `zh/` — simplified Chinese documentation (canonical)
- `en/` — English documentation

The structure intentionally mirrors the old `redefine-docs-v2` site: index, getting started, configuration, content, page templates, plugins, deployment and migration guides. Each locale has its own `meta.json` for sidebar navigation.

All example URLs use the reserved `example.com` domain (`https://*.example.com`) so they are safe to copy and replace.
