Redefine for Astro is an Astro port of Hexo Theme Redefine. It keeps the original typography, cards, callouts and page structure, while rebuilding the content pipeline with Astro content collections, static routes and `remark-directive`.

It is designed for personal blogs, technical notes and documentation-style sites: articles are Markdown files and the build output is plain static HTML with no UI framework runtime.

## Features

- Markdown / content collections; articles, archives, categories, tags and search index are generated automatically
- Home banner, typewriter subtitle, fixed or static background
- Light / dark mode, table of contents, reading progress, font size controls
- Word count, reading time, copyright, related posts, previous / next navigation
- Local search, RSS, Mermaid, APlayer, image viewer
- Artalk / Waline / Giscus / Twikoo / Gitalk / Utterances comments
- Friends, essays, masonry, bookmarks and 404 templates
- Tailwind CSS v4 with a single user configuration file
- Optional ClientRouter navigation
